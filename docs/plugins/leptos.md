# Leptos Plugin

This plugin installs a basic [Leptos](https://github.com/leptos-rs/leptos) frontend scaffold and enables the `leptos` feature.

## Usage

```bash
ferrum add leptos
ferrum compile gen/app.yaml
```

The plugin copies the `frontend_leptos/` crate and default templates. See [docs/leptos.md](../leptos.md) for development and build instructions.
